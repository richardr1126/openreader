---
title: Audiobook Export
description: Turn a document into an M4B or MP3 audiobook.
---

Export a whole document as an audiobook file. Open the document and choose **Export audiobook** in the reader header. If you don't see it, an admin has turned audiobook export off.

## Export a document

1. Under **Settings**, choose the **Voice**, the **Format** (M4B or MP3), and the **Audiobook speed**.
2. Choose **Generate**. OpenReader generates any audio that is missing and reuses everything you have already listened to.
3. When generation finishes, choose **Build file** to assemble the audiobook, then **Download**.

Generation runs on the server, so you can close the dialog or the document while it works. **Stop** pauses it and **Resume** continues where it stopped. The voice is locked while generating; stop the export to change it.

The **Chapters** list (**Pages** for a PDF) shows the progress of each part. Each finished part can be downloaded on its own.

## Where the file is kept

Finished audiobooks are stored with your document, so you can download them again later without regenerating. They count toward the document's storage, and are removed when you delete the document's audio or the document itself (see [Library](./library#storage-and-your-data)).
