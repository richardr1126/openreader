title: Keyboard Shortcuts
description: Keys for playback, navigation, and selecting documents.

## Reader

| Keys | Action |
| --- | --- |
| Space | Play or pause |
| ← / → | Skip back or forward one sentence |
| Shift+← / Shift+→ | Previous or next page (PDF) or section |
| `<` / `>` | Slower or faster playback |
| Esc | Close the open side panel |

The playback keys work while the reader has focus, including inside an EPUB. They are ignored while you type in a field or use a menu, slider or dialog. Turn them off with **Keyboard shortcuts** in **Settings → Reading**.

## Library

| Keys | Action |
| --- | --- |
| Cmd/Ctrl-click, Shift-click | Select documents |
| Cmd/Ctrl+A | Select every visible document |
| Esc | Clear the selection |

## Desktop app

| Keys | Action |
| --- | --- |
| Cmd/Ctrl+O | Open a document from your computer |
